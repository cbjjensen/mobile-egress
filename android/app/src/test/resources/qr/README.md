# Disposable QR decoder fixture

`direct-v2-upright.txt` contains the QR module grid encoding the `invitation` string from the public,
disposable `testdata/direct-v2-wire.json` interoperability fixture. It contains
no customer data and was not captured from an installed Client.

It is generated by the production Go QR encoder at medium correction. Each row
contains `1` for black and `0` for white, including its four-module quiet zone.
Tests render it at four pixels per module. ZXing 3.5.3 misses this dense matrix upright but detects
it after a quarter turn. Tests compare the decoded text to the shared fixture,
so changing its contents requires regenerating this grid too.

To regenerate, set `MOBILE_EGRESS_QR_TEST_OUTPUT` to a disposable local directory
and run:

```powershell
go test ./windows-client/internal/clientapp -run '^TestDensePairingQRPreservesWholeReadableModules$' -count=1
```

Sample each 4-by-4 pixel module of that directory's `direct.png` into the text
grid (`1` black, `0` white, one row per line). Do not substitute a real invitation
or customer screenshot.
