Download the accepted 2.x MobileEgressClientSetup.exe from the official GitHub release.
Run it normally and verify the established publisher before Windows elevation.
The installer contains the Client app and background service.

Open Mobile Egress Client on the workload computer. Configure a reachable public
HTTPS endpoint (default local TCP listener 8443), then choose Pair phone.
Scan the private invitation with the compatible Mobile Egress phone app.

Start sharing on the phone and copy this Client's local HTTP or SOCKS proxy into
the intended application. On iPhone, leave Mobile Egress open and unlocked;
keep-awake prevents auto-lock only. Manual lock or app switching pauses traffic.

Upgrades from 1.x require fresh direct pairing. Historical controller installers
and phone builds are incompatible with direct mode.
