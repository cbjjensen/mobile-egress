Download MobileEgressSetup.exe from the official GitHub release and double-click it.
The installer contains all Mobile Egress files. No ZIP extraction is needed.
If using an older ZIP release, extract the whole ZIP and run its Setup executable.

Setup installs Mobile Egress and, if missing, Microsoft's WebView2 runtime.
Keep an internet connection available and wait for the app to open.
The native setup window shows the current stage. This can take several minutes.
If runtime setup fails, check the connection and choose Retry; this retries only
WebView2. You can also open Mobile Egress from the Start menu to finish later.

Later, open Mobile Egress from the Start menu.
Follow the Next step card in the app to finish connecting your devices.
